DHIS2 Notice Guide

Put a maintenance notice on top of the login page of one or many DHIS2 instances, and have it removed automatically when the window is over.

Pon un aviso de mantenimiento encima del mensaje de la pantalla de login de una o varias instancias DHIS2, y que se quite solo al terminar la ventana.

0The idea in one pictureLa idea en un esquema

1Add a new noticeAñadir un aviso nuevo

A notice is two small files in notices/: the text (HTML) and a JSON that says where and until when. Easiest path: copy the example.

Un aviso son dos ficheros pequeños en notices/: el texto (HTML) y un JSON que dice dónde y hasta cuándo. Lo más fácil: copiar el ejemplo.

  1. Copy the exampleCopia el ejemplo

    cd /path/to/dhis2_notice
cp notices/example.html notices/2026-11-13-prod.html
cp notices/example.json notices/2026-11-13-prod.json

  2. Write the message (HTML)Escribe el mensaje (HTML)

    It is published exactly as written, so the colour and alignment go inside the file. Always in English.

    Se publica tal cual, así que el color y la alineación van dentro del fichero. Siempre en inglés.

    <center><span style="color:red"><b>
Scheduled update: this instance will be upgraded on 13 November 2026 from 09:00 to 13:00 CET.<br/>
The system may be unavailable during this period. Sorry for the inconvenience.
</b></span></center>

  3. Fill in the JSONRellena el JSON

    {
  "servers": ["prod"],                      // server keys and/or groups from servers.json
  "end": "2026-11-14 09:00",                // when it is removed (Europe/Madrid)
  "message_file": "2026-11-13-prod.html"    // the HTML, next to this file
}

    Remove the // comments in the real file (JSON does not allow them). Optional "locale": "fr" writes the notice only to that language.

    Quita los comentarios // en el fichero real (JSON no los admite). Opcional: "locale": "fr" escribe el aviso solo en ese idioma.

  4. Check, then dry runComprueba y simula

    ./dhis2_notice.py check prod                                     # credentials found? current message?
./dhis2_notice.py apply notices/2026-11-13-prod.json --dry-run   # validates, changes nothing

  5. ApplyAplica

    ./dhis2_notice.py apply notices/2026-11-13-prod.json

    It prints a summary (servers, URLs, end time, text). Type y to publish; anything else cancels.

    Muestra un resumen (servidores, URLs, hora fin, texto). Escribe y para publicar; cualquier otra cosa cancela.

  6. Verify and forgetVerifica y olvídate

    Open a login page to see the banner, and run ./dhis2_notice.py status: the job must be active. Cron removes it after the end time.

    Abre un login para ver el banner y ejecuta ./dhis2_notice.py status: el job debe estar active. Cron lo quita pasada la hora fin.

Rules: end must be in the future. A server can have only one active notice per language. To change a running notice, restore it first and apply again.

Reglas: end debe estar en el futuro. Un servidor solo puede tener un aviso activo por idioma. Para cambiar uno en curso, haz restore y vuelve a aplicar.

2How to run itCómo se ejecuta

CommandComandoWhat it doesQué hace
./dhis2_notice.py check <server|group>Read-only. Shows which credentials are used and the current message.Solo lectura. Muestra qué credenciales usa y el mensaje actual.
apply notices/x.json --dry-runValidates and shows the summary. Changes nothing.Valida y muestra el resumen. No cambia nada.
apply notices/x.jsonSummary, asks y/N, publishes and saves the job.Resumen, pregunta y/N, publica y guarda el job.
apply … --minutes 5Testing: ignores the file's end, ends in 5 minutes.Pruebas: ignora el end del fichero, termina en 5 minutos.
statusLists jobs and their state.Lista los jobs y su estado.
restore [job-id]Removes the notice now (all open jobs, or one).Quita el aviso ya (todos los jobs abiertos, o uno).
tickRemoves notices whose end has passed. Cron runs it; it prints nothing if there is nothing to do.Quita los avisos cuya hora fin pasó. Lo ejecuta cron; no imprime nada si no hay nada que hacer.

Cron (once, on the server)

Cron (una vez, en el servidor)

mkdir -p state
crontab -e
# add:
0 * * * * cd /path/to/dhis2_notice && python3 dhis2_notice.py tick >> state/tick.log 2>&1

An empty state/tick.log is normal. To see what happened use ./dhis2_notice.py status and tail state/notice.log.

Un state/tick.log vacío es normal. Para ver qué pasó usa ./dhis2_notice.py status y tail state/notice.log.

3Where things liveDónde está cada cosa

PathRutaPurposePara qué
dhis2_notice.pyThe script (Python 3.9+, no dependencies).El script (Python 3.9+, sin dependencias).
servers.jsonServers, groups, timezone. No secrets.Servidores, grupos, zona horaria. Sin secretos.
~/.dhis2_tokensCredentials (PAT or user:password), chmod 600. Never printed or logged.Credenciales (PAT o usuario:contraseña), chmod 600. Nunca se imprimen ni se registran.
notices/Your notices (.json + .html). Never modified by the script.Tus avisos (.json + .html). El script nunca los modifica.
state/jobs/One file per apply. Do not delete active ones: they hold the text to remove.Un fichero por apply. No borres los active: contienen el texto a quitar.
state/notice.logTimestamped actions with URL and added/removed text.Acciones con fecha y hora, URL y texto añadido/quitado.

4If something goes wrongSi algo falla

MessageMensajeMeaningSignificado
401 … token does not existsWrong token, or a token from another instance.Token incorrecto, o de otra instancia.
401 … http method is not allowedThe PAT does not allow GET and/or POST.El PAT no permite GET y/o POST.
403 Access is deniedThe user cannot edit system settings.El usuario no puede editar ajustes del sistema.
'x' not found in the passwords filecredentials_key does not match an entry (case sensitive).credentials_key no coincide con ninguna entrada (distingue mayúsculas).
already have an active noticeRun status, then restore.Ejecuta status y luego restore.
notice block not found … left untouchedSomeone already removed or edited it by hand. Nothing was changed.Alguien ya lo quitó o editó a mano. No se cambió nada.

Job state restore_failed means the removal did not work: read state/notice.log, fix the cause and run restore.

El estado restore_failed indica que no se pudo quitar: lee state/notice.log, corrige la causa y ejecuta restore.
